# Excipients Zone link page

A responsive, mobile-first landing page designed for QR-code and visiting-card sharing.

## Deploy with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then Save.
4. GitHub Pages should publish at `https://pranjaltiwari95.github.io/ez-linktree/` after the deployment finishes.
